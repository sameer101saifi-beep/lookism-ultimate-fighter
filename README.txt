LOOKISM – UNLIMITED FIGHTERS  ->  Android APK

Tumhara index.html bilkul waisa hi (www/index.html) rakha hai, koi change nahi.

APK banane ka sabse aasan tareeka (PC pe kuch install nahi karna):
1. github.com pe free account banao -> New repository (Private ya Public).
2. Is folder ki saari files (hidden .github folder ke saath) repo mein upload karo.
3. Repo mein "Actions" tab kholo -> "Build APK" -> workflow chalne do (5-8 min).
4. Complete hone pe us run ke neeche "Lookism-APK" artifact download karo, zip kholo.
5. app-debug.apk ko phone mein bhejo, install karo ("Unknown sources" allow karna padega).

App landscape + fullscreen mein khulegi, progress (story save) phone mein save rahega.
